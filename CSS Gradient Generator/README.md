# 🎨 CSS Gradient Generator

A tool for web design students to visually create CSS gradients and copy the code.

## Features
- 🎨 Pick 2–3 gradient colors with color pickers
- 🔄 Toggle between Linear / Radial gradient
- 📐 Angle slider for linear gradients
- 👀 Live preview panel
- 📋 One-click copy of CSS code

## Usage
Open `index.html` in your browser.  
Choose colors, gradient type, and angle.  
Preview updates live and copy the CSS code with one click.
