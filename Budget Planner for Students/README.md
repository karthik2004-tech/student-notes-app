# 💰 Budget Planner for Students

A student-focused monthly budget planner where users can set a monthly budget, add income/expense entries with categories, and view a real-time remaining balance with a visual breakdown chart.

## Features
- 📅 Set monthly budget amount
- ➕ Add categorized income/expense entries
- 💵 Real-time balance display
- 📊 Pie chart breakdown by category
- 💾 localStorage persistence across sessions
- 🧹 Clear all / reset month functionality
- 🎨 Clean, responsive design

## Usage
Open `index.html` in your browser.  
Set your monthly budget, add entries, and track your balance.  
View category breakdowns in the chart and save data automatically with localStorage.
