# 🧘 Zen Focus Timer (No Distractions Mode)

A minimalist distraction-free timer for deep study sessions — different from Pomodoro in that it has no breaks and shows calming visuals.

## Features
- ⏱️ Set a custom duration (15 / 30 / 60 min or custom)
- 🌑 Full-screen minimal dark mode
- 🌬️ Ambient background animation (subtle breathing circle)
- 🔔 Sound alert when done
- 📝 Session log saved in localStorage
- 🎨 Clean, calming design

## Usage
Open `index.html` in your browser.  
Choose a duration and start the timer.  
Stay focused with calming visuals until the alert sound plays.  
Session logs are saved locally for review.
