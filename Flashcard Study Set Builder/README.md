# 📚 Flashcard Study Set Builder

A flashcard app where students can create custom study sets with question/answer pairs, flip cards to reveal answers, navigate through the deck, and track how many they got right vs wrong in a session.

## Features
- ➕ Create/edit/delete flashcard decks
- 🔄 Flip card animation on click
- ⬅️➡️ Previous/Next navigation
- ✅❌ Right/Wrong self-marking with session score
- 💾 localStorage to save decks
- 🎲 Shuffle mode
- 🎨 Clean, responsive design

## Usage
Open `index.html` in your browser.  
Enter questions and answers, save decks, and study interactively.  
Flip cards to reveal answers, mark right/wrong, and track your score.
