# 📊 GPA Calculator

A semester GPA and CGPA calculator tailored for Indian university students (10-point and 4-point scale).

## Features
- ➕ Add subjects with credit hours and grade/marks
- 🔢 Auto-calculate SGPA (current semester)
- 📚 Add multiple semesters to compute CGPA
- 🔄 Toggle between 10-point (Indian) and 4-point (US) scale
- 📤 Export results as plain text
- 🎨 Clean, responsive design

## Usage
Open `index.html` in your browser.  
Add subjects with credits and grades, calculate SGPA, save semesters, and compute CGPA.  
Toggle scale as needed and export results.
