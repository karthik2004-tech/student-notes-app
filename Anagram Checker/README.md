# 🔄 Anagram Checker

A utility tool for English / linguistics students to check if two words are anagrams of each other.

## Features
- ✍️ Two input fields for words
- ⚡ Real-time check on input
- 📊 Show character frequency breakdown
- 🚫 Ignore spaces and case
- 🎬 Visual YES/NO result with animation

## Usage
Open `index.html` in your browser.  
Type two words and see if they are anagrams.  
Character frequency breakdown is shown for both words.
