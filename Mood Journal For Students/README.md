# 🌈 Mood Journal for Students

A daily mood-tracking journal where students can log how they're feeling each day with an emoji picker, add a short note, and view a monthly mood history calendar — promoting mental wellness alongside academic productivity.

## Features
- 😀 Daily emoji mood picker (5 levels: great → terrible)
- 📝 Optional short note per entry
- 📅 Monthly calendar view with mood colors
- 🔥 Streak counter for logging consistency
- 💾 localStorage persistence
- 🎨 Clean, responsive design

## Usage
Open `index.html` in your browser.  
Pick your mood, add a note, and save.  
View your monthly calendar with mood history and track streaks.
