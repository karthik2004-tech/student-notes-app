# 📝 Quick Notes with Color Tags

A lightweight sticky-notes-style quick capture tool where students can jot down notes instantly, tag them with a color label (subject/topic), pin important ones to the top, and search/filter by tag.

## Features
- ✍️ Instant note creation
- 🎨 Color tag picker per note (yellow, pink, green, blue)
- 📌 Pin to top functionality
- 🔍 Search/filter by color tag
- ✏️ Edit/delete notes
- 💾 localStorage persistence
- 🎨 Clean, responsive design

## Usage
Open `index.html` in your browser.  
Add notes, tag them with colors, pin important ones, and filter/search easily.  
Notes persist across sessions with localStorage.
