# 🎮 Simon Says Memory Game

A classic Simon Says colour sequence memory game — tests short-term memory and pattern recognition.

## Features
- 🔴🟦🟩🟨 4 coloured buttons (red, blue, green, yellow)
- 🤖 Computer plays a random sequence; player repeats it
- ➕ Sequence grows by 1 each round
- 🔊 Sound + flash feedback for each button
- 💀 Game over animation
- 🏆 High score saved in localStorage
- 🎨 Clean, responsive design

## Usage
Open `index.html` in your browser.  
Press **Start Game** and repeat the sequence shown.  
Try to beat your high score!
