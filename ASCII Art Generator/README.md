# 🎨 ASCII Art Generator

A fun tool that converts typed text into large ASCII art banners — popular with CS students and terminal lovers.

## Features
- ⌨️ Type any text and see it rendered as ASCII art
- 🎭 Choose from 3–4 font styles (block, bubble, shadow, standard)
- 📋 Copy output to clipboard
- 🖥️ Monospace preview panel with dark background
- 📤 Download as `.txt` file
- 🎨 Clean, responsive design

## Usage
Open `index.html` in your browser.  
Type text, select a font style, and click **Generate**.  
Copy or download the ASCII art for use in terminals, projects, or fun banners.
