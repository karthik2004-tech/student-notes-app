# ⏱️ Stopwatch with Lap Functionality

A fully functional stopwatch with lap recording — different from the basic stopwatch already in the repo by adding lap management and export.

## Features
- ▶️ Start / Pause / Reset controls
- 🏁 Lap button to record split times
- 📊 Lap history list with time differences
- 🟩 Highlight best lap
- 🟥 Highlight worst lap
- 📤 Export laps as `.txt` file
- 🎨 Clean, responsive design

## Usage
Open `index.html` in your browser.  
Start the stopwatch, record laps, and view lap history with best/worst highlighted.  
Export lap history as a `.txt` file for sharing or record keeping.
