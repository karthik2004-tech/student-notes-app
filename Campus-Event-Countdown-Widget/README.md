# 🎓 Campus Event Countdown Widget

A widget where students can add upcoming events (exams, fests, deadlines) and see live countdowns.  
Built with **HTML, CSS, and JavaScript**.

## Features
- ➕ Add event name + date/time
- ⏳ Live countdown showing days, hours, minutes, seconds
- 🎨 Color changes as event approaches (green → yellow → red)
- 🗑️ Delete events once passed
- 💾 Saved in localStorage

## Usage
Open `index.html` in your browser.  
Add events, track countdowns, and manage them easily.
