# Healthcare Appointment & Patient Management Platform

A modern, highly-polished web application simulating a full-scale healthcare portal with dedicated dashboards for Patients, Doctors, and Administrators.

## Features Included
- **Simulated Role-Based Access Control (RBAC)**: Switch between Patient, Doctor, and Admin views with simulated JWT verification.
- **Doctor Dashboard**: Manage appointment cards (accept, reject, diagnose), update availability schedule, build and sign prescriptions, and view SVG-based performance metrics.
- **Patient Dashboard**: Dynamic booking form, check appointment logs, view medical records, and download or print custom prescriptions.
- **Admin Dashboard**: System reports, user status controls, and overall clinic performance logs.
- **Notifications & Toast Alerts**: Modern UI notifications of upcoming appointments.
- **Persisted State**: High-fidelity mock DB stored inside `localStorage` using `try/catch` safety checks.
- **Dark/Light Theme**: Harmonizes seamlessly with the global repository settings.
