# 📘 Science Formula Reference Sheet

A reference sheet for commonly used formulas in **Physics, Chemistry, and Maths**.  
Built with **HTML, CSS, and JavaScript**.

## Features
- Categorized tabs: Physics / Chemistry / Maths
- 🔍 Search bar to find formulas quickly
- 📑 Formula cards with name, expression, and variable definitions
- 📱 Responsive card grid layout
- ⌨️ Keyboard shortcut (Ctrl + /) to focus search

## Usage
Open `index.html` in your browser.  
Select a category, search formulas, and view them in a responsive grid.
