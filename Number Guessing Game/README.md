# 🎲 Number Guessing Game

A classic number guessing game where the computer picks a random number and the student guesses it.

## Features
- 🔢 Computer picks number between 1–100
- 📈 Hints: "Too high!" / "Too low!"
- 🧮 Attempt counter
- 🏆 Best score saved in LocalStorage
- 🔄 Restart button with animation

## Usage
Open `index.html` in your browser.  
Enter a guess, get hints, and try to beat your best score!
