# ⚡ Internet Speed Test UI

A visually appealing internet speed test interface using a public speed-test API or image download benchmark.

## Features
- 🕹️ Animated speedometer gauge
- 📡 Measure download speed via timed image fetch
- 📶 Display ping and download Mbps
- ⭐ Speed rating (Slow / Fair / Good / Excellent)
- 📝 Test history log for the session
- 🎨 Clean, responsive design

## Usage
Open `index.html` in your browser.  
Click **Run Test** to measure ping and download speed.  
View the animated gauge, rating, and session history.
