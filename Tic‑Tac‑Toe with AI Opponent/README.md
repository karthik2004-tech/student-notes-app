# ❌⭕ Tic-Tac-Toe with AI Opponent

An upgraded tic-tac-toe game where students can play against another player or an unbeatable AI opponent powered by the minimax algorithm.

## Features
- 🎮 Two modes: Player vs Player and Player vs AI
- 🤖 AI uses minimax for unbeatable play
- 🏆 Win/draw/lose detection with highlight
- 📊 Score tracker across rounds
- 🔄 Restart button with animation
- 🎨 Clean, responsive design

## Usage
Open `index.html` in your browser.  
Choose a mode (PvP or AI) and start playing.  
Track scores across rounds and restart anytime.
