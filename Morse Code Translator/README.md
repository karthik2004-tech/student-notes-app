# 📡 Morse Code Translator

A fun educational tool to convert **text ↔ Morse code** with audio playback.  
Built with HTML, CSS, and JavaScript.

## Features
- Text → Morse conversion in real time
- Morse → Text decoding
- Audio playback using Web Audio API
- Copy output to clipboard
- Clean minimal UI with status messages
- LocalStorage persistence of last translation

## Usage
Type text, convert to Morse, play audio, or decode Morse back to text.
