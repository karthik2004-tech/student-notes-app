# 🪑 Exam Seat Randomiser

A classroom tool to randomly assign students to exam seats — useful for teachers and student reps.

## Features
- 🔢 Input number of rows and columns (grid layout)
- 📝 Paste or type a list of student names
- 🎲 Click "Randomise" to assign names to seats
- 🪑 Visual seat grid display
- 📤 Export seating plan as text
- 🖨️ Print-ready view
- 🎨 Clean, responsive design

## Usage
Open `index.html` in your browser.  
Enter rows, columns, and student names.  
Click **Randomise** to generate the seating plan.  
Export or print the plan for distribution.
