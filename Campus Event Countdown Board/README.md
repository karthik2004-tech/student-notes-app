# 🎉 Campus Event Countdown Board

A visually appealing event countdown board where students can add upcoming college events (fests, exams, submissions, club meetings) and see live countdowns displayed as animated cards.

## Features
- ➕ Add multiple events with name, date, time, and category tag
- ⏳ Live countdown timers (days : hours : mins : secs)
- 🎨 Category color coding (Exam, Fest, Submission, Meeting)
- 🗑️ Auto-remove or archive past events
- 💾 localStorage persistence
- 🎨 Clean, responsive card-board layout

## Usage
Open `index.html` in your browser.  
Add events, view countdowns, and manage your board.  
Past events auto-remove, and data persists across sessions.
