# 🎵 Music Tempo BPM Tapper

A BPM (beats per minute) detector for music students — tap a key to the beat and get the tempo.

## Features
- 🖱️ Tap button or SPACEBAR to the beat
- 🧮 Calculate average BPM based on tap intervals
- 🎼 Show tempo label (Slow, Moderate, Fast, Very Fast)
- ⏱️ Reset after inactivity (3 seconds)
- 💡 Animated pulse on each tap

## Usage
Open `index.html` in your browser.  
Tap along to the beat using the button or spacebar.  
Watch the BPM and tempo label update in real time.
