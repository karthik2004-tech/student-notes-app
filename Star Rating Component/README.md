# ⭐ Star Rating Component

A reusable animated star rating UI component — useful for beginners learning CSS hover effects and JS events.

## Features
- ⭐ 5-star interactive rating
- ✨ Hover highlight effect
- 🖱️ Click to lock a rating
- 📊 Display selected rating as text ("4 out of 5")
- 🎨 Smooth CSS transitions

## Usage
Open `index.html` in your browser.  
Hover over stars to preview rating, click to lock, and see the selected rating displayed below.
