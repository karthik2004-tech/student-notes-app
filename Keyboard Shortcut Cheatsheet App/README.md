# ⌨️ Keyboard Shortcut Cheatsheet App

A responsive cheatsheet app for students to quickly reference **VS Code, Linux, Chrome, and Windows shortcuts**.  
Built with HTML, CSS, and JavaScript.

## Features
- Dropdown to select tool
- Categorized shortcuts in card grid
- Search/filter by keyword
- Highlight matches
- Category filter buttons
- Keyboard shortcut (Ctrl + /) to focus search

## Usage
Select a tool, search or filter shortcuts, and view them in a responsive grid.
