# 🖖 Rock Paper Scissors Lizard Spock

The extended Big Bang Theory version of Rock Paper Scissors — a fun break for students between study sessions.

## Features
- 🪨📄✂️🦎🖖 5 choices: Rock, Paper, Scissors, Lizard, Spock
- 🤖 Computer picks randomly
- 🎬 Show result with animated icons
- 📊 Running score tracker (wins / losses / draws)
- 📜 Rules reference card shown on hover
- 🎨 Clean, responsive design

## Usage
Open `index.html` in your browser.  
Choose your move and see if you can beat the computer.  
Hover over the rules section to view the reference card.
