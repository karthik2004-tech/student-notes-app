# 🔢 Roman Numeral Converter

A simple converter between **Arabic numbers (1–3999)** and **Roman numerals**.  
Built with **HTML, CSS, and JavaScript**.

## Features
- Arabic → Roman conversion
- Roman → Arabic conversion
- Instant real-time conversion
- Input validation with helpful status messages
- Clean card-style UI
- Keyboard shortcut (Ctrl + Enter) for quick conversion

## Usage
Open `index.html` in your browser.  
Type a number or Roman numeral to see instant conversion.
