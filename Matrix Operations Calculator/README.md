# 🧮 Matrix Operations Calculator

A visual matrix calculator for CS and Math students studying linear algebra.

## Features
- 🔢 Enter 2×2 or 3×3 matrices via input grid
- ➕ Perform Addition
- ➖ Perform Subtraction
- ✖️ Perform Multiplication
- 🔄 Transpose Matrix A or B
- 📐 Determinant calculator for Matrix A or B
- 📊 Step-by-step result display
- 🎨 Clean grid-based UI

## Usage
1. Open `index.html` in your browser.
2. Select matrix size (2×2 or 3×3).
3. Enter values into both matrices.
4. Choose an operation (Add, Subtract, Multiply, Transpose, Determinant).
5. View the result displayed step-by-step in a styled grid.

## Benefits
- Helps CS and Math students practice linear algebra visually.
- Provides clear step-by-step results for better understanding.
- Lightweight, browser-based, no dependencies.
- Attractive UI with responsive design.

## Tech Stack
- **HTML** → Structure and input grids
- **CSS** → Grid layout, styled cards, responsive design
- **JavaScript** → Matrix operations, determinant logic, transpose, rendering results
