# ✖️ Multiplication Table Generator

A visual multiplication table generator for maths students in lower grades.

## Features
- 🔢 Input a number (1–20) to generate its multiplication table
- 📊 Display 1× to 12× results in a styled card grid
- 🟩 Highlight multiples that are also perfect squares
- 🔄 Option to toggle full NxN table view
- 🎨 Clean, responsive design

## Usage
Open `index.html` in your browser.  
Enter a number and generate its multiplication table.  
Toggle full NxN view to see the complete multiplication grid.
