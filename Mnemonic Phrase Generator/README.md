# 🧠 Mnemonic Phrase Generator

A study tool that helps students create memorable acronyms and mnemonics for lists of terms.

## Features
- 📝 Input a list of words (e.g. OSI layers, planets)
- 🤖 Auto-generate mnemonic sentences from first letters
- 🎭 Suggest multiple variations
- ⭐ Save favourite mnemonics to localStorage
- 📋 Share as a copyable text card
- 🎨 Clean, responsive design

## Usage
Open `index.html` in your browser.  
Enter a list of words, click **Generate Mnemonics**, and view suggested phrases.  
Copy or save your favourites for study sessions.
