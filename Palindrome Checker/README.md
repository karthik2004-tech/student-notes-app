# 🔄 Palindrome Checker

A fun app for students to check if words, phrases, or sentences are palindromes.

## Features
- 📝 Input any text
- 🔍 Check ignoring spaces, punctuation, and case
- 🎬 Character-by-character comparison animation
- 📚 Examples: "racecar", "A man a plan a canal Panama"
- 🕒 History of checked strings

## Usage
Open `index.html` in your browser.  
Enter text, click **Check**, and watch the animation + history log.
