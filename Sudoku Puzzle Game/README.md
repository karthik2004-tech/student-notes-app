# 🧩 Sudoku Puzzle Game

A classic Sudoku game with auto-generated puzzles — great for CS students who want to practice logic.

## Features
- 🎲 Auto-generate valid Sudoku puzzles
- 🎚️ 3 difficulty levels: Easy / Medium / Hard
- ✨ Highlight selected row, column, and box
- ❌ Error detection (highlight wrong entries in red)
- ⏱️ Timer + "New Game" button
- 🎨 Clean, responsive design

## Usage
Open `index.html` in your browser.  
Select difficulty, click "New Game," and solve the puzzle.  
Errors are highlighted in red, and the timer tracks your progress.
