# 📌 Assignment Deadline Tracker

A deadline management tool for students to add assignments with subject name, due date, and priority level. Displays all assignments sorted by urgency with color-coded status (due today, upcoming, overdue).

## Features
- ➕ Add assignment with subject, due date, priority (High/Medium/Low)
- 🔄 Auto-sort by urgency
- 🎨 Color indicators: red (overdue), orange (due today), green (upcoming)
- ✅ Mark as submitted
- 💾 localStorage persistence
- 🔍 Filter by subject or priority
- 🎨 Clean, responsive design

## Usage
Open `index.html` in your browser.  
Add assignments, track deadlines, and mark submissions.  
Filter by subject or priority and view urgency-based sorting.
