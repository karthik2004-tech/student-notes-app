# 🎯 Hangman Word Game

A classic Hangman game with a word bank focused on CS and science vocabulary for students.

## Features
- 📚 Random word from categorised word bank (CS, Biology, Geography)
- 🎹 On-screen keyboard (A–Z buttons)
- 🎨 SVG hangman drawing that builds step by step (6 chances)
- 🏆 Win / lose animations
- 💡 Hint button (shows category of the word)
- 🎨 Clean, responsive design

## Usage
Open `index.html` in your browser.  
Click **New Game** to start, guess letters using the on-screen keyboard, and try to solve the word before the hangman is complete.  
Use the **Hint** button to reveal the category.
