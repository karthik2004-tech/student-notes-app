# 📅 Exam Timetable Generator

A visual exam timetable builder where students can enter subject names, exam dates, and times to generate a clean, color-coded weekly schedule view. Includes countdown to the next exam.

## Features
- ➕ Add subject, date, time, venue entries
- 🎨 Color-coded subject cards on a calendar-style grid
- ⏳ Countdown to nearest upcoming exam
- ✏️ Edit/delete entries
- 💾 localStorage persistence
- 🖨️ Print/export view
- 🎨 Clean, responsive design

## Usage
Open `index.html` in your browser.  
Add exam details, view the timetable, and track countdowns.  
Export or print the timetable for easy reference.
