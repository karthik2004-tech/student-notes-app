# 💻 Code Snippet Saver

A lightweight **Code Snippet Manager** built with HTML, CSS, and JavaScript.  
Helps students save, highlight, and copy useful code snippets.

---

## ✨ Features
- Add snippets with title, language tag, and code
- Syntax highlighting using highlight.js
- Copy to clipboard button per snippet
- LocalStorage persistence
- Clean, responsive UI

---

## 🚀 How to Use
1. Enter snippet title, language, and code.
2. Click **Add Snippet**.
3. View saved snippets with syntax highlighting.
4. Click **Copy** to copy code to clipboard.
