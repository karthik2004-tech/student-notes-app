# ⚛️ Periodic Table Quiz

A quiz app that tests students on **element symbols, atomic numbers, and groups** from the periodic table.  
Built with **HTML, CSS, and JavaScript**.

## Features
- 🎲 Random questions (symbols, atomic numbers, groups)
- 📝 Multiple choice (4 options)
- 🏆 Score tracker with streak counter
- 🎚️ Difficulty toggle: Easy (first 20 elements) / Hard (all 118)
- 📊 End screen with percentage score

## Usage
1. Select difficulty (Easy or Hard).
2. Click **Start Quiz**.
3. Answer questions and track your score + streak.
4. At the end, view your percentage score and restart if desired.
