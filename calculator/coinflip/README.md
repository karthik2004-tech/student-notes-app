# 🎲 Coin Flip & Dice Roller

A probability learning tool — flip a coin or roll dice with animations and track frequency results.  
Built with **HTML, CSS, and JavaScript**.

## Features
- 🪙 Animated coin flip (Heads/Tails)
- 🎲 Dice roller with 1–6 dice options
- 📜 Result history log
- 📊 Frequency chart (Heads vs Tails)
- 📈 Probability stats shown in real time

## Usage
Open `index.html` in your browser.  
Flip the coin or roll dice, view results, and track probabilities.
