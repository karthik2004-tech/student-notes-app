# 🌐 Responsive Navbar Component

A reusable **responsive navigation bar** built with HTML, CSS, and JavaScript.  
Beginners can learn hamburger menu patterns with smooth transitions.

## Features
- Desktop: horizontal nav links
- Mobile: hamburger icon → slide-in menu
- Smooth CSS transitions
- Clean, reusable component

## Usage
Include `index.html`, `style.css`, and `script.js` in your project.  
Resize the browser to see the responsive behavior.
